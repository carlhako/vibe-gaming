# Pop-up Panic: Windows 95 Edition (v3)

A browser game that simulates a Windows 95 desktop being overrun by aggressive pop-up advertisements. The player must click the **X** button on each pop-up window to close it before the screen fills up. If too many pop-ups accumulate, the system crashes with a Blue Screen of Death (BSOD). Every so often a special **boss pop-up** appears — a demonic, red-tinted window that actively dodges the cursor to make closing it much harder. Defeating a boss spawns extra pop-ups as a "reward." The game escalates: pop-ups spawn faster over time, the max-popup limit adjusts to screen size, and the desktop includes authentic Win95 chrome (taskbar, Start menu, clock, desktop icons).

## File map

| File | Purpose |
|------|---------|
| `index.html` | Minimal shell: `<head>` metadata, viewport, title; loads `style.css` and all JS modules in dependency order; contains the static DOM skeleton (`#screen`, `#desktop` icons, `#popup-container`, `#taskbar`, `#start-menu`, `#bsod`). |
| `style.css` | All CSS: CSS custom properties for the Win95 palette, layout for desktop/taskbar/popups/BSOD, animations (`popupAppear`, `bossPulse`, `bossEmojiShake`, `adPulse`, `marqueeBlink`, `bsodBlink`), boss-popup themed overrides, responsive breakpoints for small screens. |
| `config.js` | Game constants and configuration: DOM element references, initial spawn delay, boss-spawn threshold range, ad content pools (`adPool`, `bossAdPool`), helper functions (`getDesktopBounds`, `clamp`, `getPopupSize`, `getRandomAd`, `getRandomBossAd`, `getSpawnDelay`, `updateMaxPopups`, `updateScoreDisplay`, `updateClock`). |
| `popups.js` | Pop-up window lifecycle: `createPopupElement` (builds the DOM for a pop-up, attaches close-button and titlebar-drag listeners, appends to container), `closePopup` (remove with shrink animation, update score, handle post-boss reward spawns), `bringToFront` (z-index reorder on click), `spawnPopup` (decide normal vs boss, call `createPopupElement`, update spawn state, trigger BSOD if limit exceeded), `scheduleNextSpawn` (set timer for next `spawnPopup`). |
| `boss.js` | Boss-specific dodge mechanic: `getCloseButtonCenter`, `distanceToCloseButton`, `triggerBossDodge` (move boss to a new random position with dodge animation, tighten detection radius, cooldown), `handleBossMouseMove` / `handleBossTouchMove` (track cursor proximity to the X button and trigger dodge when cursor enters the danger zone), `attachBossListeners` / `detachBossListeners`, `resetBossState`. |
| `input.js` | Global input handling: drag-and-drop for pop-up windows (`startDrag`, `onMouseMove`, `onTouchMove`, `endDrag`), document-level mouse/touch listeners, Start-menu toggle and item handlers, desktop-icon click feedback, touch-scroll prevention on the pop-up container. |
| `game.js` | Top-level game orchestration: game-state variables (`activePopups`, `totalClosed`, `totalSpawned`, `gameOver`, etc.), boss-state variables, `triggerBSOD` (freeze everything, show BSOD overlay), `restartGame` (full reset of all state and DOM), resize handler, BSOD restart listener (click/touch/keydown), initial spawn kickoff and clock interval. Loads last so it can reference every other module; calls `updateMaxPopups`, `updateScoreDisplay`, `updateClock`, and fires the first spawn timers at load time. |
